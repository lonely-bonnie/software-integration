跨进程探针初次暴露只复制密文无法解密：Chromium 的 Local State 包含受 Windows 保护的密钥状态，迁移必须一起保留。加密测试须正常退出以刷新密钥状态，立即 app.exit 会丢弃尚未持久化的状态。已修复并加入 `npm run verify:migration` 可重复检查；初次失败候选未发布到 GitHub，修复后重新生成并验收。

实际用户设置 SHA256：`681ec8bf7fd9b427fc2eec0c97801aaf2d2818e8b4ece92b801bda8013259936`。账户截图与测试 Token 不进入仓库，临时证据在验收后清理。默认便携运行自检为 live，Codex ready（1 个服务端窗口），DO unconfigured；隔离凭据探针没有真实 DO Token，也未发送 DO 查询。

界面设计沿用 0.2.0。本次不宣称重新验收所有 DPI 或所有安装器交互路径；0.2.0 的位置、快捷方式两种选择、卸载和开机启动交互结论见 [0.2.0 历史记录](archive/validation-0.2.0.md)。[0.1.x 历史记录](archive/validation-0.1.x.md) 仅对应早期便携包。
