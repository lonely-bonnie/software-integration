# AstraDesk 0.2.1 Beta

清理更名前的开发命名和过程残留，规范发行目录与版本管理。

- 开发环境改为 AstraDesk-Dev；程序仍可选择任意安装位置。内部桥接与诊断环境变量统一为 AstraDesk。
- 用户数据改为 `%APPDATA%/AstraDesk`，自动校验并复制旧设置和 Windows 加密凭据。保留原数据供回退，已有新配置不覆盖；失败使用原目录并提示。
- 保留安装器升级 GUID，0.2.0 可原位升级。正常升级、卸载保留用户配置。
- releases 根目录直接提供按版本命名的安装器、便携版和 SHA256SUMS；增加索引、完整性检查、重复版本保护和生成目录清理命令。
- 仅保留选用美术素材、正式测试和脱敏验收结论。历史正式包保持原始内容和校验值。

下载 Windows x64 `AstraDesk-0.2.1-windows-x64-setup.exe`，选择安装位置与桌面快捷方式。另提供 portable.exe。软件包含运行环境，无需安装 Node。

延续默认流萤、四主题和中英文设置。未签名，使用手动更新；第二台电脑验收、真实 DO 接入仍待完成。0.1.x 仅有历史便携版，未提供安装器。
