# AstraDesk 0.2.0 Beta

Rider Console 更名为 **AstraDesk**。新安装默认流萤主题，支持中文 / English，网站入口与监控模块独立使用。

下载 `AstraDesk-0.2.0-windows-x64-setup.exe`，选择安装语言、目录和桌面快捷方式。安装器包含运行环境，注册开始菜单及 Windows 卸载入口；无需安装 Node。`portable.exe` 为便携选项。

新增通用设置、时区、开机启动、启动到托盘、减少动画、配置导入导出、恢复默认偏好和关于/更新/反馈入口。品牌、版本、默认配置、迁移、翻译与模块清单集中管理。

旧版配置与 Windows 加密 Token 保持兼容，普通升级和卸载保留个人配置。可分享的配置不含 Token、Droplet ID 和 Codex 本机路径；朋友需使用自己的只读 DO Token、Droplet 和 Codex CLI 登录。

本版为未签名 Beta，采用手动下载更新。已完成本机核心测试、构建、双语和安装流程验证；另一台独立电脑尚待验收。DO 计费累计、历史数据库、自动更新和桌宠窗口暂未实现。

校验下载文件：

```powershell
Get-FileHash .\AstraDesk-0.2.0-windows-x64-setup.exe -Algorithm SHA256
```

与同一 Release 的 `AstraDesk-0.2.0-SHA256SUMS.txt` 对照。问题反馈请附版本、Windows 版本和复现步骤，移除 Token 与私人账户信息。
